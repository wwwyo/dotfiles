# cloudflare

## 文脈

この開発環境は dotfiles と mise で復元し、CLI のバージョンを固定している。npm global への直接インストールや moving target は、この管理を迂回してしまう。

## 意図

Cloudflare の API 操作は `cf` に揃えつつ、既存の Wrangler プロジェクトの開発・ビルド・デプロイは維持する。skill の利用を理由に移行を発生させない。共通設定が定めるツール管理・検索時の秘密情報の扱い・依存の固定方針と整合させ、製品選定と同梱 reference は原本を活かす。

製品選択の入口と必要な実装ガイドを保ち、広い製品表は用途別に参照する。全製品の表を毎回読む負荷を減らしつつ、製品ごとの選択条件と docs fallback は維持する。
