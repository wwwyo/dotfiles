# learn の適応意図

ユーザーが所有する学習スキルの名前を `learn` に統一し、QingYunA/answer-me-with-html の原稿から図解・動画を描画するエンジンを使う。旧 learn の個別制作を毎回繰り返さず、原本の自動配置・部品・単一ファイル出力を保つ。

形式未指定では音声付き動画を学習の入口に置く。短い定義や単純な手順、ユーザーが指定した形式は尊重する。読者が知る隣接概念との比較を入口に置く。教材を渡して終わらず、別例への適用など本人の理解が見える回答を待ち、誤解に合わせて説明と確認を繰り返す。閲覧だけを理解済みと扱わない。

音声には旧learnと同じFish Audioの無料モデルと試聴済み話者「さとる」を使う。モデルを省略・誤指定すると有料モデルへフォールバックするAPIのため、正しい無料モデルを明示し、認証不足・API失敗時に別モデルやproviderへ自動で切り替えない。音声長に基づく図と字幕の同期を保つ。日本語の表示文と読み上げ文を分け、読みを修正した場合は音声キャッシュにも反映する。認証情報は環境のmise + age運用に従う。音声仕様はskill本文とCLIのhelpで説明し、削除したnarration referenceは再作成しない。教材を作るagentと音声生成モデルを区別し、環境側のモデル選択・ツール管理・ブラウザ運用の正本を重複させない。

MP4書き出しは利用環境にあるH.264エンコーダーを使い、libx264が無いmacOSでも標準のVideoToolboxで生成できるようにする。教材のためだけに追加ライブラリやffmpegの再ビルドを必須にしない。既存のlibx264環境の画質設定と、Fish音声・字幕・図の同期は保つ。
