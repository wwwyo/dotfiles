# 合意済み材料

課題: 研究者が同僚へコレクションを見せるため、毎回メモを別文書にコピーしている。原本を直してもコピーには反映されない。
導出: コレクションを読み返して次の問いを決める作業を、同僚との検討にも広げる。
解: 所有者が読み取り専用の共有リンクを発行し、受取人はログインせずリンクからそのコレクションの現在の内容を読める。所有者はリンクを失効させられる。
除外: 共同編集、閲覧者の本人確認、通知、共有履歴の分析。
モデル: コレクションはメモを0件以上含む。各メモは必ず1つのコレクションだけに属する。コレクションの所有者だけが共有リンクを発行・失効できる。共有リンクは必ず1つのコレクションを対象にする。同時に有効にできるリンク数は未確定。
用語: 共有リンク（ShareLink）は今後も複数の共有機能で同じ実体を指す。『匿名閲覧』はこの機能の利用形態だけを指す。
既存決定: メモの単一所属は ADR-0001 で確定済み。
評価: コアアクションは研究者が共有リンクを発行して同僚へ渡すこと。期待頻度は週次。自発的に開いた利用者のうち共有リンクを発行した人数を数え、通知経由は除く。主指標は onboarding 後の翌週にも共有リンクを発行して戻った割合。目標値はまだ決めていない。
重要な追加 NFR は今回はなし。
prototype: scratch/share-prototype/index.html を所有者と受取人の両方の視点で確認し、この解で合意した。再配布不能素材は含まれない。
レビュー合意: 実装方式を書かず、未確定のリンク数を確定事項にしないこと。その他の残指摘なし。
