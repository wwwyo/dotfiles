保存ボタン — 8状態

NoteShelf の tokens.css と design.md のみを参照した保存ボタンの全状態。実ページのボタンは状態ごとに class / 属性を持ち替你わるだけで、このマークアップは共通です。

インタラクション

  • default data-state なし · accent 塗り / 白
  • hover .is-hover が :hover を強制表示
  • focus .is-focus が :focus-visible を強制表示 · リングは即時
  • active .is-active が押下を強制表示 · 1px 沈む
  • disabled disabled 属性 · label は『保存』のまま

非同期の状態（data-state）

  • loading data-state="loading" + aria-busy · 回転は reduced motion で減速
  • error data-state="error" · 枠 + アイコン + 文言の3経路
  • success data-state="success" · トーストは出さない（画面変化が結果）
色の出所

色は tokens.css のみ。component 側で hex / oklch を追加していません（gate 48）。追加したのは spacing・radius・duration・easing の token だけです。

コントラスト

手計算の WCAG 2.1 比（ブラウザ測定ではありません）。白 / accent 6.8:1 · 白 / accent-hover 9.6:1 · focus #111827 / 白 15.9:1 · error #a11220 / 白 8.0:1 · success #116b35 / 白 6.6:1 · disabled は opacity 0.55 適用前 ink / paper-2 で 12.8:1（非 actives なので WCAG 1.4.3 の除外対象）。

focus ring

focus と accent の素の組合せは 2.6:1 で 3:1 未満のため、2px の paper ハロで塗りから分離しています。_ring 自体は白地に載ります。

幅の固定

min-inline-size 7.5rem は『保存』→『保存中…』→『保存済み』を切り替えてもレイアウトが崩れないための推定値です。文言がこれより長くなった場合はここを見直してください。

保存処理

この scope の外です。data-state の切り替え・aria-live による読み上げ・success の自動解除は保存処理側の責務として未実装のままです。
