# バックアップが成功と報告されても、復元できるとは限らない

バックアップの処理が正常に終わったことを示すログがあっても、それだけで復元できるとは限らない。ログが示しているのは保存が完了した段階までで、復元した環境でサービスが動くかどうかは、保存とは別の段階として確かめることになる。

## 週次バックアップ3件のうち1件はサービスを起動できなかった

先週、運用担当者が検証環境で週次バックアップ3件の復元を試した。うち1件には設定ファイルが含まれておらず、サービスを起動できなかった。ログを調べたところ、保存対象の指定が変更されていた可能性がある。ただし、その指定を変更した主体は分かっていない。

残る2件はサービスを起動できたが、すべての機能は確かめていない。ここでの結果は、サービスが立ち上がる範囲の確認にとどまる。

## 成功ログが示さないこと

バックアップの成功ログは保存処理の終了を示す。復元した後のサービスの状態がどうだったかは、このログからは分からない。保存の成功を復元の成功と同じものとして扱うわけにはいかない。

## 復元検査で検出できる範囲

先週の検査で対象になっていたのは、検証環境でサービスを起動するところまでである。復元検査は、含めなかった障害を検出できない。

次に運用担当者が行うのは、保存対象の指定を調べ、設定ファイルを含めたバックアップで再び復元を試すことである。
