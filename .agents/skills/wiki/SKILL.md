# Wiki

canonical は `~/src/github.com/wwwyo/me/wiki/`。cwd が me の worktree 内なら、その checkout を参照する。存在しなければ「wwwyo/me リポジトリが見つかりません」と報告する。

## 保存先を先に決める

| 残す内容 | 正本 |
| --- | --- |
| repo/PJ で採用した方針、設計判断、選択理由・却下案・トレードオフ | 対象 repo の ADR（既存の配置・規約に従う） |
| 再利用する作業手順、運用プロセス、判断時のチェック | 対象 repo の既存 skill / reference。全 repo 共通の手順は dotfiles の skill |
| repo の制約・構造、skill の起動条件 | 対象 repo の AGENTS.md（詳細は ADR / skill へリンク） |
| ユーザーが議論・学習で到達した、別文脈にも転用できる概念・洞察 | wiki の既存ページ |
| 個人の目標・PJ の位置づけ・フォーカス | wiki の PJ ページ。repo の決定・手順は正本へのリンクのみ |
| セッションの経緯・一時メモ / 資料の転記 | Langfuse / daily / raw（wiki の対象外） |

**repo の決定や手順を「新しい理解」「判断の背景」と呼び替えて wiki に保存しない。** repo 側に正本があれば本文を重複させず、必要なときだけリンクする。対象 repo が不明・書けないことは wiki に代替保存する理由にならない。未配置として報告する。repo を持たない個人の判断は、個人の目標・理解として wiki に残せる。

## 必要な分だけ参照する

1. ユーザーが wiki 参照を求めた、過去の個人の判断が必要、または対象 repo の code・AGENTS・ADR・skill だけでは必要な背景が不足する場合に検索する。通常の実装・設定変更で「関連しそう」だけを理由に事前読込しない。
2. 自然文は下の router を使い、候補はまず 3 件の title / description で選ぶ。具体語・既知のページは `rg -l` で対象を絞る。検索結果だけを根拠に回答しない。
3. 最有力の **1 ページ**で `rg -n '^#{1,6} |<具体語>' <path>` を使い、必要な節だけ `sed -n '<開始>,<終了>p' <path>` で読む。全文・候補全件を一括で開かない。通常は本文合計 4,000 字程度を目安にし、別ページは未解決の問い・矛盾・根拠の確認に必要なときだけ読む。
4. 問いに答える根拠が得られたら止める。相互リンクは自動で辿らない。足りない場合は不足する点を明確にして検索を 1 回絞り直す。それでも外れる場合だけ root `index.md` の Map の該当行 → 該当 domain index の候補行へ進む。index 全文を連鎖して読まない。明示された網羅調査は目的に応じて範囲を広げてよい。
5. 同じセッションで確認済みの節は再読込しない（変更・矛盾がある場合を除く）。参照した結論と根拠のパス・節を短く保持する。回答には実際に確認したページの絶対パスリンクを付ける。見つからなければ「今回の検索範囲では wiki に該当エントリなし」と伝え、捏造・自動作成しない。

```bash
python3 <このスキルのbase directory>/tools/wiki_route.py route "検証のしやすさと委譲の判断" --top 3 --json
```

分類は frontmatter の domain（`tags` 先頭）× `type`。dir や更新日だけで関連性を判断しない。router の bigram fallback の score は確信度ではないので、title / description と実際の節で確認する。

`route` の問いと `links` の対象本文は TypeSafe（外部 API）へ送られうる。業務・顧客の固有名を含む問いは `--local-only` を付けるか一般化する。`.local` ページを対象にした `links` と `--local-only` は外部送信・log 保存をしない。cwd による自動抑止はない。非公開ページは router の候補から除かれるため、必要なら対象 domain を絞ってローカルの `rg` で検索する。

## 書き戻すときだけ読む

保存先が wiki で、ユーザー自身の新しい理解があるときに限り [references/write.md](references/write.md) を読む。参照だけなら書き込み手順・wiki/AGENTS.md・PJ 一覧を読み込まない。
