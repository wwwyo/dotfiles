# ADR Format

Use document's [ADR guideline](../../document/references/adr.md) and
[ADR template](../../document/assets/adr.md) when creating or updating an ADR.
They own the format, placement, numbering, and decision lifecycle rules, based
on Google Cloud's public ADR guidance.

The conditions for offering an ADR during domain modeling remain in
[Offer ADRs sparingly](../SKILL.md#offer-adrs-sparingly). An explicit user request
to write or update an ADR does not need to meet those offering conditions.
