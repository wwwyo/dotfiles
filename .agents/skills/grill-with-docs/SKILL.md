# Grill with Docs

[grilling](../grilling/SKILL.md) と [domain-modeling](../domain-modeling/SKILL.md) の両方を読み、併用する。特定の harness の tool 名には依存しない。

- 質問の前提関係、回答待ち、合意の確認は grilling に従う。
- 合意した用語は Glossary、戻しにくい重要な判断は ADR に記録する。書式と記録の条件は domain-modeling に従う。
- 呼び出し側が ADR の保存先を指定した場合はそちらを使う。記録内容をユーザーの未回答から推測しない。
