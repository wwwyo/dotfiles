# 障害・不具合調査レポート（incident）

障害・不具合・不審な挙動を調べた結果のレポート型。材料と構成は [reporting](../SKILL.md)、語彙・図解・描画は [learn](../../learn/SKILL.md) に従う。

## 並び順

読者が追う因果の順: **症状 → 原因 → 対処**。調査の時系列・発見した順には並べない（調査の経緯自体は読者の関心ではない）。

- panel = 事象単位。1 つの障害に複数の不具合が絡むなら不具合ごとに分ける

「症状」「原因」「対処」は本文の小見出しに使う。panelの見出しには対象の事象や解決した内容を示す。

## 各パートの書き方

- 症状: 観測された事実を箇条書き（エラー文・影響範囲・再現条件）
- 原因: 特定した根因を因果の文で書く（「A が B だったため C になった」）。推定段階のものは「（推定）」と明記
- 対処: 実施済み・これからの対応を箇条書き。未実施は「（未実施）」など状態を付ける。再発防止は独立panelにせず対処の項目に含める

## 書かないもの

- 調査プロセスの時系列（いつ何を確認したか）
- 却下した仮説の羅列（結論の信頼性に関わる場合を除く）
