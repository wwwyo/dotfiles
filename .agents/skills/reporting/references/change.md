# 変更レポート（非 UI）

設定変更・データ移行・コード構造の変更など、画面を持たない「変更」のレポート型。材料と構成は [reporting](../SKILL.md)、語彙・図解・描画は [learn](../../learn/SKILL.md) に従う。

## 並び順

処理の流れ順に並べる。ファイル一覧順・作業した順・レビュー回順にしない。

- データ移行: 読み取り → 変換 → 書き込み → 検証
- 構造変更: 入口 → 呼び出し → 末端
- 設定変更: 変更箇所の依存順（上位の設定 → その利用側）

## 構成

- panel = 領域（機能・サブシステム・設定グループ）単位
- 変更点は箇条書きで書く。1項目につき1変更とし、動詞で終える文にする
- 設定値・状態の変化は「項目 / 反映前 / 反映後」のMarkdown表で示す。変わっていない項目は書かない
